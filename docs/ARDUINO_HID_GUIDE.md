# Arduino HID 使用指南

## 概述

Arduino HID 是一种通过真实硬件设备模拟键盘/鼠标输入的方案。由于输入来自真实的USB设备，操作系统和游戏无法区分它与真人操作，这使其成为**最难被反作弊系统检测**的输入方式。

## 与其他方案的对比

| 特性 | SendInput (pyautogui) | ctypes_raw | Interception | **Arduino HID** |
|------|----------------------|------------|--------------|-----------------|
| 检测难度 | 容易 | 中等 | 较难 | **极难** |
| 需要驱动 | 否 | 否 | 是 | 否 |
| 需要重启 | 否 | 否 | 是 | 否 |
| 需要硬件 | 否 | 否 | 否 | **是** |
| 延迟 | ~1ms | ~1ms | ~0.5ms | ~5-15ms |
| 成本 | 免费 | 免费 | 免费 | ¥15-50 |

## 硬件要求

### 支持的开发板

| 开发板 | 芯片 | 价格 | 购买链接建议 |
|--------|------|------|-------------|
| **Pro Micro** (推荐) | ATmega32U4 | ¥15-20 | 淘宝/拼多多 |
| Arduino Leonardo | ATmega32U4 | ¥30-50 | 官方/淘宝 |
| Teensy 2.0 | AT90USB1286 | ¥100+ | PJRC官网 |
| Teensy 4.0 | ARM Cortex-M7 | ¥200+ | PJRC官网 |

**推荐:** Pro Micro，小巧便宜，功能完整。

### 购买注意事项

1. 确保购买的是 **ATmega32U4** 芯片的板子
2. 避免购买 ATmega328P 的板子（如 Arduino Uno/Nano，不支持原生HID）
3. 确认卖家提供的是 5V/16MHz 版本

## 安装步骤

### 第一步：安装 Arduino IDE

1. 下载 Arduino IDE: https://www.arduino.cc/en/software
2. 安装并启动

### 第二步：连接 Arduino

1. 使用 USB 数据线连接 Pro Micro 到电脑
2. Windows 会自动安装驱动

### 第三步：上传固件

1. 打开 Arduino IDE
2. 打开 `arduino/MapleHID/MapleHID.ino`
3. 选择正确的开发板：
   - **工具 → 开发板 → Arduino Leonardo** (如果使用 Pro Micro)
4. 选择正确的端口：
   - **工具 → 端口 → COMx** (选择新出现的端口)
5. 点击上传按钮 (→)
6. 等待上传完成，看到 "Done uploading"

### 第四步：测试连接

```bash
# 列出所有可用端口
python tests/test_arduino_hid.py --list

# 快速测试连接（需要指定端口）
python tests/test_arduino_hid.py --port COM5 --quick

# 完整功能测试
python tests/test_arduino_hid.py --port COM5
```

**注意:** 上传固件后，Arduino 的 COM 端口可能会改变（通常是 COM 编号增加）。使用 `--list` 查看当前端口。

### 第五步：配置软件

在 `config/config_custom.yaml` 中添加:

```yaml
anti_detect:
  input_backend: "arduino_hid"
  arduino:
    port: ""              # 留空自动检测，或指定如 "COM5"
    auto_detect: true     # 自动检测端口
    enable_batch: true    # 启用批量命令（推荐）
```

### 第六步：安装 Python 依赖

```bash
pip install pyserial
```

## UI 界面使用

程序运行后，切换到 **"Arduino HID"** 标签页，可以看到：

1. **连接状态**: 显示当前连接状态、端口、设备ID、延迟
2. **命令日志**: 实时显示发送和接收的所有命令
3. **错误日志**: 显示错误信息

### 重要提示

> **UI 连接状态说明：**
> - 启动程序后，Arduino HID 面板初始显示 "未连接"
> - 点击 **Start** 按钮启动机器人后，Arduino HID 后端才会被初始化
> - 此时切换到 "Arduino HID" 标签页，即可看到连接状态
> - 即使配置使用其他输入后端（如 ctypes_raw），Arduino HID 面板仍会显示连接状态

### 重新连接

如果连接断开，可以：
1. 点击 UI 中的 "重新连接" 按钮
2. 或者拔插 USB 线，程序会自动重连

## 延迟优化

### 批量命令

启用批量命令可以显著降低延迟：

```yaml
arduino:
  enable_batch: true
```

原理：将多个命令合并为一次串口传输，减少往返延迟。

### 优化效果

| 模式 | 单键延迟 | 5键组合延迟 |
|------|---------|------------|
| 普通模式 | ~10ms | ~50ms |
| 批量模式 | ~10ms | ~15ms |

## 通信协议

### 命令格式

```
<命令字符><数据>\n
```

### 命令列表

| 命令 | 格式 | 说明 | 示例 |
|------|------|------|------|
| K | K<扫描码> | 按下按键 | `K1E` (按下 A) |
| R | R<扫描码> | 释放按键 | `R1E` (释放 A) |
| P | P<扫描码> | 按下并释放 | `P1E` (点击 A) |
| M | M<dx>,<dy> | 移动鼠标 | `M10,5` |
| C | C<按钮> | 鼠标点击 | `C1` (左键) |
| B | B<cmd1>;<cmd2>... | 批量命令 | `BK1E;W50;R1E` |
| ? | ? | 心跳检测 | `?` → `OK` |
| I | I | 设备信息 | `I` → `MAPLE_HID_V1` |
| X | X | 释放所有 | `X` |

### 扫描码对照表

```
方向键: left=4B, right=4D, up=48, down=50
字母: a=1E, b=30, c=2E, d=20, e=12, ...
数字: 0=0B, 1=02, 2=03, ...
功能键: space=39, enter=1C, esc=01, ...
```

## 故障排除

### 问题: 找不到设备

1. 检查 USB 线是否是数据线（不是充电线）
2. 尝试换一个 USB 口
3. 检查设备管理器中是否有 Arduino 设备
4. 重新安装 Arduino 驱动
5. 使用 `--list` 参数查看当前端口

### 问题: 上传失败

1. Pro Micro 需要在复位后立即上传
2. 快速双击 RST 按钮进入 bootloader 模式
3. 立即点击上传

### 问题: 按键无响应

1. 运行测试脚本检查连接
2. 检查串口是否被其他程序占用
3. 重启 Arduino

### 问题: 延迟过高

1. 确保启用了批量命令
2. 检查 USB 是否连接到 USB 3.0 口
3. 关闭其他使用串口的程序

## 安全建议

1. **不要在公共场合使用** - 硬件设备容易被发现
2. **保持固件更新** - 定期检查是否有新版本
3. **合理使用** - 即使不可检测，过度使用仍可能引起怀疑

### 为什么不可检测？

1. **硬件层面**: Arduino 通过 USB 向电脑报告自己是一个标准 HID 设备
2. **驱动层面**: Windows 使用标准 HID 驱动处理输入
3. **API层面**: 输入事件没有 `LLKHF_INJECTED` 标志
4. **应用层面**: 游戏收到的是完全正常的键盘/鼠标事件
