# MapleStory AutoLevelUp 源代码文档

## 项目概述

MapleStory AutoLevelUp 是一个用于冒险岛（MapleStory）游戏的自动练级机器人。该项目使用计算机视觉技术来识别游戏画面，并通过模拟键盘输入来控制游戏角色自动进行练级活动。

## 核心特性

1. **自动打怪** - 通过图像识别检测怪物并自动攻击
2. **路线巡逻** - 按照预设的路线图在地图中移动
3. **符文解谜** - 自动检测并解决符文谜题
4. **自动喝药** - 监控HP/MP并自动使用药水
5. **换频道** - 检测到其他玩家时自动换频道
6. **反检测** - 内置人性化行为模拟以避免被检测

## 工作流程

1. **启动阶段**
   - 加载配置文件
   - 初始化各个模块（键盘控制器、游戏窗口捕获器、健康监控器等）
   - 设置有限状态机的初始状态

2. **主循环**
   - 捕获游戏窗口画面
   - 检测小地图位置和玩家位置
   - 执行当前状态的逻辑
   - 检查状态转换条件
   - 发送键盘命令

3. **状态管理**
   - Hunting（狩猎）：正常打怪状态
   - FindingRune（寻找符文）：符文出现时寻找符文
   - NearRune（接近符文）：接近符文时尝试触发
   - SolvingRune（解决符文）：解决符文谜题
   - Patrol（巡逻）：简单巡逻模式
   - Auxiliary（辅助）：辅助模式

## 配置文件

- `config/config_default.yaml` - 默认配置
- `config/config_custom.yaml` - 用户自定义配置
- `config/config_macOS.yaml` - macOS 平台特定配置
- `config/config_data.yaml` - 地图和怪物数据
