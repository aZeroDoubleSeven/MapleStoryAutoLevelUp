## 快速开始（无需重启）

### 方案一：使用 ctypes_raw 后端（推荐，无需任何安装）

这是默认配置，**无需安装任何驱动，无需重启电脑**。

1. 确保配置文件 `config/config_default.yaml` 中设置：

```yaml
anti_detect:
  input_backend: "ctypes_raw"
```

2. 直接运行程序即可：

```bash
python src/main.py
```

### 工作原理

ctypes_raw 后端通过以下方式规避检测：

- 直接调用 Windows API (`SendInput`)
- 使用 `KEYEVENTF_SCANCODE` 标志
- 提供硬件扫描码 (Hardware Scancode)
- 配合人类行为模拟（随机延迟、按键时长变化等）

## 反检测原理

### 游戏如何检测脚本

| 检测方法 | 说明 | pyautogui 是否被检测 | ctypes_raw 是否被检测 |
|----------|------|---------------------|----------------------|
| LLKHF_INJECTED 标志 | Windows 给模拟输入添加的标志 | ❌ 会 | ⚠️ 会（Windows 限制） |
| 缺少硬件扫描码 | 真实键盘有硬件扫描码 | ❌ 会 | ✅ 不会 |
| 时序分析 | 按键间隔过于规律 | ❌ 会 | ✅ 不会（已随机化） |
| API Hook | 监控 SendInput 调用 | ❌ 会 | ⚠️ 可能 |

### ctypes_raw 的优势

```
┌────────────────────────────────────────────────────────────┐
│                    pyautogui 的问题                         │
├────────────────────────────────────────────────────────────┤
│  pyautogui.keyDown('a')                                    │
│       ↓                                                    │
│  SendInput(虚拟键码, 无扫描码, 无特殊标志)                   │
│       ↓                                                    │
│  Windows 添加 LLKHF_INJECTED 标志                          │
│       ↓                                                    │
│  反作弊检测到"注入输入" → 判定为脚本                        │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│                    ctypes_raw 的改进                        │
├────────────────────────────────────────────────────────────┤
│  ctypes_raw.key_down('a')                                  │
│       ↓                                                    │
│  SendInput(                                                │
│      wVk=0,                    # 不使用虚拟键码             │
│      wScan=0x1E,               # 使用硬件扫描码 ✓          │
│      dwFlags=KEYEVENTF_SCANCODE  # 扫描码模式 ✓            │
│  )                                                         │
│       ↓                                                    │
│  输入包含硬件特征，更接近真实键盘                           │
└────────────────────────────────────────────────────────────┘
```

## 输入后端说明

### 1. ctypes_raw（推荐，无需重启）

**优点：**
- ✅ 无需安装驱动
- ✅ 无需重启电脑
- ✅ 无需管理员权限
- ✅ 包含硬件扫描码
- ✅ 兼容性好

**缺点：**
- ⚠️ 仍有 LLKHF_INJECTED 标志（Windows API 限制）
- ⚠️ 非常严格的反作弊可能仍能检测

**适用场景：**
- 大多数游戏
- 不想安装额外驱动
- 需要快速部署

### 2. interception（效果最好，需要重启）

**优点：**
- ✅ 内核级别模拟
- ✅ 无 LLKHF_INJECTED 标志
- ✅ 几乎无法被检测

**缺点：**
- ❌ 需要安装驱动
- ❌ 需要重启电脑
- ❌ 需要管理员权限

**适用场景：**
- 有严格反作弊的游戏
- 可以接受重启电脑

### 3. pyautogui（不推荐）

**优点：**
- ✅ 简单易用
- ✅ 跨平台

**缺点：**
- ❌ 容易被检测
- ❌ 无硬件扫描码
- ❌ 有注入标志

**适用场景：**
- 无反作弊的游戏
- 测试用途

## 配置选项详解

在 `config/config_default.yaml` 中的 `anti_detect` 部分：

```yaml
anti_detect:
  # 输入后端选择
  input_backend: "ctypes_raw"  # auto / ctypes_raw / interception / pyautogui
  
  # 按键时长随机化
  key_duration_base: 0.05       # 基础按键时长（秒）
  key_duration_variance: 0.03   # 变化范围（±30毫秒）
  
  # 动作延迟随机化
  action_delay_min: 0.02        # 最小延迟
  action_delay_max: 0.08        # 最大延迟
  
  # 攻击冷却变化
  attack_cooldown_variance: 0.15  # ±15%
  
  # 微停顿设置（模拟人类短暂分神）
  micro_pause_probability: 0.05   # 5% 概率
  micro_pause_duration_min: 0.1
  micro_pause_duration_max: 0.3
  
  # 闲置行为（模拟人类发呆）
  idle_probability: 0.01          # 1% 概率
  idle_duration_min: 0.5
  idle_duration_max: 2.0
  
  # Buff 技能时间变化
  buff_timing_variance: 0.2       # ±20%
  
  # 喝药时间变化
  potion_timing_variance: 0.25    # ±25%
  
  # 功能开关
  enable_random_delays: True
  enable_micro_pauses: True
  enable_idle_behavior: True
  enable_typing_variance: True
```

### 调整建议

| 场景 | 建议配置 |
|------|----------|
| 反作弊较严格 | 增加 variance 值，提高随机性 |
| 追求效率 | 降低 pause/idle 概率 |
| 长时间挂机 | 启用 idle_behavior |

## 进阶配置（需要重启）

如果 ctypes_raw 仍被检测，可以考虑安装 Interception 驱动：

### 安装步骤

1. **下载 Interception 驱动**

   访问：https://github.com/oblitum/Interception/releases
   
   下载最新版本的 `Interception.zip`

2. **安装驱动（需要管理员权限）**

   解压后，以管理员身份运行命令提示符：
   
   ```cmd
   cd Interception\command line installer
   install-interception.exe /install
   ```

3. **重启电脑**（必须）

   驱动需要在系统启动时加载

4. **安装 Python 库**

   ```bash
   pip install interception-python
   ```

5. **修改配置**

   ```yaml
   anti_detect:
     input_backend: "interception"
   ```

6. **以管理员身份运行程序**

   ```bash
   # 右键点击命令提示符，选择"以管理员身份运行"
   python src/main.py
   ```

## 常见问题

### Q: ctypes_raw 后端无法正常工作？

A: 请检查：
1. 是否在 Windows 系统上运行
2. Python 是否有足够权限
3. 游戏窗口是否处于前台

### Q: 按键没有响应？

A: 可能的原因：
1. 游戏窗口不是激活状态
2. 按键名称拼写错误
3. 尝试切换到 pyautogui 后端测试

### Q: 仍然被检测？

A: 可以尝试：
1. 增加随机延迟范围
2. 降低操作频率
3. 安装 Interception 驱动（需要重启）

### Q: macOS 上如何使用？

A: 目前反检测功能仅支持 Windows。macOS 会自动降级使用 pyautogui。
